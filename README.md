# HOLO • 3D Card Forge ◈

เปลี่ยนรูปถ่าย 2 มิติ ให้กลายเป็น **การ์ด 3 มิติสไตล์ SSR** ที่พลิก / หมุน / มีแสงวิ่งบนการ์ดแบบ holographic — เล่นบนมือถือได้เต็มจอ ไม่ต้องติดตั้งอะไร ไม่มี dependency

![theme](https://img.shields.io/badge/theme-futuristic-5ef0ff) ![mobile](https://img.shields.io/badge/mobile-ready-b46bff)

## ฟีเจอร์
- 🖼️ **อัปโหลดรูปถ่าย** จากเครื่อง แล้วขึ้นเป็นหน้าการ์ดทันที
- 🔄 **พลิกการ์ด** ดูด้านหน้า/ด้านหลัง (แตะการ์ด หรือปุ่ม “พลิก”)
- 🖐️ **หมุนการ์ดอิสระ** ด้วยการลากนิ้ว/เมาส์ (มี easing ลื่น ๆ)
- 🎯 **ไจโรสโคป** เอียงมือถือแล้วการ์ดหมุนตามจริง (รองรับการขอสิทธิ์บน iOS 13+)
- ✨ **แสง holographic แบบการ์ด SSR** — foil สายรุ้ง + ประกายกลิตเตอร์ + ไฮไลต์แสง วิ่งตามตำแหน่งนิ้ว/การเอียง
- ℹ️ **ปุ่มข้อมูลการ์ด** ตั้งชื่อ / ความหายาก / ธาตุ / พลัง / เรื่องราว แล้วโชว์ที่ด้านหลังการ์ด
- 📱 ดีไซน์ธีมล้ำอนาคต (neon grid + glow) เต็มจอ รองรับ safe-area ของมือถือ

## วิธีใช้
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเสิร์ฟแบบ static:

```bash
python3 -m http.server 8080
# เปิด http://localhost:8080 บนมือถือ (ต่อ Wi‑Fi เดียวกัน) หรือเดสก์ท็อป
```

> หมายเหตุ: ฟีเจอร์ไจโรสโคปต้องเปิดผ่าน **HTTPS** หรือ `localhost` และผู้ใช้ต้องกดอนุญาตสิทธิ์เซ็นเซอร์บน iOS

## โครงสร้างไฟล์
| ไฟล์ | หน้าที่ |
|------|---------|
| `index.html` | โครงหน้า การ์ด และแผงข้อมูล |
| `style.css`  | ธีม, เอฟเฟกต์ 3D, holographic foil, แสง |
| `app.js`     | การลากหมุน, ไจโร, พลิก, อัปโหลดรูป, แผงข้อมูล |

ทุกอย่างเป็น vanilla HTML/CSS/JS — ไม่มี build step และไม่ต้องต่อเน็ต
